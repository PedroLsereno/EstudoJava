## Variáveis
Java é uma **linguagem fortemente tipada**, ou seja, você deve informar o tipo de dado a ser utilizado naquela variável.

E o que é variável?
É uma forma de armazenar uma informação na memória.

Existe alguns tipos de variáveis, porém, por agora sera falado apenas da `Variável Local`.

> [!NOTE]
> **Como declarar uma variável?**
> 
> Para declarar uma variável, deve ser seguido uma sintaxe, como o exemplo abaixo:
>
> >int idade = 23;
> 
> `int` é o tipo de dado, nesse caso inteiro;
>`idade` é o nome da variável;
>`23` é o valor da variável.


Nesse caso a variável idade está recebendo o número 23.
